# Distinct editorial imagery
Twenty-seven original images created with the built-in Image Generation tool and saved under public/images/editorial/. See asset-manifest.json for the initial seven briefs; the additional prompt files below document the remaining images. Generated human scenes depict Nigerian adults or fictional Nigerian students and carry visible illustrative captions. They do not purport to show real staff, students, recipients or delivered programmes.

Homepage scenes remain on the homepage. New About, programme, movement, enterprise, internship and laptop-page scenes have distinct files/compositions. LaunchPad historical photos are not reused between its page and Gallery. Shared Forge/product marks are identity assets, not repeated editorial photography.

No unverified Pinterest or stock images were downloaded. Optimised WebPs are project assets; full generation outputs remain in Codex generated_images. No third-party stock licence purchase was needed for the additions. Existing archive permission is founder-authorised reuse, not an assertion of public-domain status.

## Whole-site imagery expansion
The pass now covers every public canonical page, using original page-specific objects, adult scenes, fictional Nigerian students and article illustrations. See page-art-prompts.json, student-prompts.json, stories-prompts.md, application-prompts.md and programme-imagery.md for generation briefs and asset mapping. Shared imagery disclosure lives in components/StudentImageNotice.tsx and /privacy#student-imagery. This is a privacy/safeguarding policy; it does not claim that all real student photography is illegal or that historical consent files have been independently audited.
