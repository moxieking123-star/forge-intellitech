# A Nigeria we can forge

21 October 2026. The founder requested a living wallpaper of contemporary Nigeria becoming a more beautiful Nigeria, a thought-provoking hero message, and additional considered site motion.

## Visual treatment

Two original AI-created landscape images show the same fictional Lagos neighbourhood, with an aligned avenue, lagoon, skyline, foreground house and palm. The future keeps Nigerian urban character, adds green public spaces, rehabilitated homes, accessible transport, cycle lanes and solar roofs. It is a vision to work towards, not a claim about a completed development or documentary photography.

The hero uses a 36-second progressive reveal, gentle camera drift, changing light and small distant birds. The question appears first; the response follows. Pause, today/possibility and autoplay controls allow visitors to choose. Reduced-motion preferences produce a static view and readable text. No video downloads, third-party animation dependency or external media service are used.

Shared page motion reveals sections once as they enter view. Keyboard focus reveals a section immediately. Content stays visible without JavaScript, and reduced-motion CSS removes transitions. Product marks receive a small hover/focus lift; the previously requested individual character-logo animations remain a separate task.
